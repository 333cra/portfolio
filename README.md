# Portfolio - Thomas L.

Mon portfolio de BTS SIO option SISR (EFREI), publié avec GitHub Pages.
La bannière avec l'onde animée reprend celle de mon site professionnel. Le reste du design est propre au portfolio.

## Pages

- `index.html` : accueil (présentation, compétences, outils, réalisations, parcours, contact)
- `realisations.html` : mes réalisations en formation, en entreprise et en freelance
- `realisation-glpi.html` : fiche détaillée du déploiement Apache / MariaDB / GLPI
- `mentions-legales.html` : mentions légales et crédits
- `confidentialite.html` : politique de confidentialité (RGPD)

## Dossiers

- `css/vendor.css` : polices et icônes
- `css/banniere.css` : bannière avec l'onde, en-tête et menu (repris de mon site pro)
- `css/portfolio.css` : tout le reste du design du portfolio
- `js/main.js` : onde, menu, filtres des réalisations, copie du mail
- `fonts/` : Bricolage Grotesque et JetBrains Mono (licence SIL OFL)
- `vendor/` : icônes Phosphor et Devicon (licence MIT)
- `img/` : logo, icône et mes captures
- `maquette/` : arborescence, wireframe et maquette

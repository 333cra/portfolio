Politique de confidentialité

En résumé : ce site ne collecte aucune donnée sur vous.

Ce que le site ne fait pas

  • Pas de cookies.
  • Pas de statistiques de visite (pas de Google Analytics ou autre).
  • Pas de formulaire : rien n'est enregistré quand vous visitez le site.
  • Pas de contenu externe : les polices et les icônes sont hébergées directement sur le site, donc votre navigateur ne contacte pas Google ni d'autres serveurs.

L'hébergeur

Le site est hébergé par GitHub Pages. Comme tout hébergeur, GitHub peut enregistrer des informations techniques sur les visites (adresse IP par exemple) pour la sécurité du service. Ces données sont gérées par GitHub, pas par moi. Plus d'infos dans la déclaration de confidentialité de GitHub.

Si vous me contactez

Si vous m'écrivez par mail à contact@veltis-it.fr, j'utilise votre message et votre adresse seulement pour vous répondre. Je ne les donne à personne.

Mes propres données

Je n'affiche que mon prénom, l'initiale de mon nom et une adresse mail de contact. Pas de photo, pas d'adresse postale, pas de téléphone.

Vos droits

D'après le RGPD, vous pouvez demander à voir, corriger ou supprimer les données que j'ai sur vous (par exemple un message que vous m'avez envoyé). Il suffit de m'écrire à contact@veltis-it.fr. Si vous pensez que vos droits ne sont pas respectés, vous pouvez faire une réclamation à la CNIL.
